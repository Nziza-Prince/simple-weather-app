# Weather App

A modern, responsive weather application built with Next.js 16, React 19, TypeScript, and Tailwind CSS v4.

## Features

- 🔍 Search weather by location
- 🌡️ Current weather conditions with temperature, feels like, humidity, wind speed, and precipitation
- 📅 7-day weather forecast
- ⏰ 24-hour hourly forecast
- 🔄 Toggle between Metric (°C, km/h) and Imperial (°F, mph) units
- 📱 Fully responsive design for mobile and desktop
- 🎨 Beautiful UI matching the Frontend Mentor design

## Tech Stack

- **Next.js 16** - React framework with App Router
- **React 19** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS v4** - Styling
- **Open-Meteo API** - Weather data (free, no API key required)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## API

This app uses the [Open-Meteo API](https://open-meteo.com/) which provides free weather data without requiring an API key.
